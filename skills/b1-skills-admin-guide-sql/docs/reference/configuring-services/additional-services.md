## Microsoft 365 Integration

With SAP Business One Microsoft 365 integration, you do not have to install Microsoft Office Word or Excel, and you can achieve the following:

- Export documents, reports and queries from SAP Business One to the Microsoft OneDrive or SharePoint as Word or Excel files
- View the exported file online in the Microsoft OneDrive or SharePoint
- Design your own export templates

For more information about configuring the Microsoft 365 integration, see Setting Up for SAP Business One Microsoft 365 Integration (https://help.sap.com/docs/SAP_BUSINESS_ONE/ac897fe631794b7db54650bb36926b76/7925d092744b402798895ca6e94699e4.html).

## SBO DI Server

This optional service enables multiple clients to access and manipulate the SAP Business One company database. To use it, you are required to have a special license.

For more information, see the SDK Help Center.

## Fax Services

SAP Business One offers fax services through Microsoft Fax Services. For more information, see *How To Install and Configure Microsoft Fax Services* on SAP Help Portal (https://help.sap.com/viewer/p/SAP_BUSINESS_ONE_PRODUCT_LINE).

This service can send several attachments as separate fax messages, added to a fax message. For supported file types, see the Microsoft documentation at www.msdn.microsoft.com (https://www.msdn.microsoft.com).

## Report Scheduling

The report scheduling function of SAP Business One allows you to schedule report execution and send generated reports via email. To do so, you must first define the mail settings and scheduled report settings. For more information, see How to Schedule Report Execution and Mailing in SAP Business One (https://help.sap.com/docs/SAP_BUSINESS_ONE/92f5332b717a49c58b82ebef5755488f/1211f88cac5a4d30a6e292a3df1c0d4a.html).

## SAP Business One Workflow

The workflow service enables you to standardize your business operations to increase overall efficiency. With predefined conditions, the system automatically executes various tasks, liberating labor resources for more creative activities.

For more information, see *How to Configure the Workflow Service and Design the Workflow Process Templates* at SAP Help Portal (https://help.sap.com/viewer/p/SAP_BUSINESS_ONE_PRODUCT_LINE). The guide includes samples and additional reference materials.
