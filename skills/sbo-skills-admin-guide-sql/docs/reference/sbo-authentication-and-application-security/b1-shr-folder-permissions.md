# B1_SHR Folder Permissions

## Application Security

SAP Business One provides features to help prevent unauthorized access to the application.

## B1_SHR Folder Permissions

The SAP Business One server installation process creates the B1_SHR folder, which contains the SAP Business One client setup files.

<!-- table: t249-01 -->
- **User**: Power User
  - **SBO_SHR Permission**: Modify and Write
- **User**: User
  - **SBO_SHR Permission**:

    Read and execute

    List folder contents

    Read
