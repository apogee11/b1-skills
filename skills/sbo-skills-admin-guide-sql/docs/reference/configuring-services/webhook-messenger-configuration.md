# Webhook Messenger (Post-Installation)

The Webhook Messenger is a background service that delivers webhook notifications to partners' webhooks when subscribed events occur. The messenger manages retries, timeouts, and message batching to ensure reliable delivery.

For more information about configuring the webhook messenger, see Web Messenger (https://help.sap.com/docs/SAP_BUSINESS_ONE/f110a154dd0f4c20bf7f3ebca9eeb794/1542ed913a414df3bf5cd202b4e1e387.html) in *Working with SAP Business One Service Layer*.
