# Admin guide (Microsoft SQL Server)

One skill for the SAP Business One Administrator's Guide, edition for Microsoft SQL Server. Never answer an installation, configuration, upgrade or security question about SAP Business One from memory: the reference below is the source. It describes one release (10.0 up to FP 2608).

## Ask

Read [docs/index.md](docs/index.md) and follow it to the single page that answers. If the reference does not cover it, say so; do not fill the gap from memory.

This edition is for installations on Microsoft SQL Server. If the developer's system runs on SAP HANA, this is the wrong skill: use `sbo-skills-admin-guide-hana`.

For building Web Client extensions use the `sbo-skills-web-client` skill; for calling the Service Layer API use the `sbo-skills-service-layer` skill. This skill is about installing and administering the systems themselves.

This skill has no Setup and does not connect to a B1 system.
